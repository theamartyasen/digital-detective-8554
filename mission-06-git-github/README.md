# Mission 6: Git and GitHub

## Objective
Understand version control and how GitHub stores project code online.

## Work Completed
Used Git to track project files, create commits, and push changes to GitHub.

## Concepts Learned
- Git: Version control system
- GitHub: Online platform for hosting repositories
- Commit: Saves a snapshot of changes
- Push: Uploads local commits
- Pull: Downloads updates from a remote repository

## Commands Used
git status, git add, git commit, git push, git log

## Understanding
Git tracks project changes and maintains history. GitHub stores projects online for sharing and collaboration.

## Evidence
Successfully committed and pushed project changes to GitHub.

## Tools Used
Git, GitHub, and Terminal.
