## 4. My understanding

A compiler translates a program before it runs, while an interpreter executes instructions during runtime. A compiler often produces an executable or another translated form. An interpreter generally carries out instructions directly. Both help computers execute programs written by programmers.

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Before execution | During runtime |
| Typical output | Executable or translated code | Program output |
| One example | C compiler | Python interpreter |
| One advantage | Fast execution after compilation | Easy to test and debug |
