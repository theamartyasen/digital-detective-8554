# Mission 1 – Computer Basics

## Task 1.1 – Trace an Activity Using IPOS

### Activity: Typing and Saving a Document

IPOS stands for Input, Processing, Output and Storage. It explains how a computer handles information.

| Stage | Description | Component |
|---|---|---|
| Input | I type text using the keyboard. | Keyboard |
| Processing | The CPU processes the typed characters and updates the document. | CPU and RAM |
| Output | The typed text appears on the screen. | Display |
| Storage | I save the document for future use. | SSD |

### My Understanding

When I type a document, the keyboard provides input. The CPU processes the data using RAM. The display shows the result, and when I save the document, it is stored on the SSD. This shows how a computer follows the IPOS cycle.


## Task 1.2 – Identify Hardware and Software

### A. Hardware

Hardware refers to the physical parts of a computer that we can touch.

| Hardware | Function |
|---|---|
| Keyboard | Used to enter text and commands. |
| Display | Shows text, images and other output. |
| Trackpad | Used to move the pointer and interact with the computer. |
| SSD | Stores files, applications and the operating system. |

### B. Software

Software refers to programs and instructions that tell the computer what to do.

| Software | Category | Function |
|---|---|---|
| macOS | Operating System | Manages computer hardware and software. |
| Safari | Application Software | Used to browse websites and access the internet. |
| Terminal | Utility Software | Allows users to interact with the computer using commands. |
| Python | Programming Software | Used to write and execute Python programs. |

### My Understanding

Hardware is the physical part of a computer, while software provides instructions to make the hardware work. Both are necessary for a computer to perform tasks.


## Task 1.3 – Computer Systems Around You

A computer-based system uses hardware and software to perform a specific task.

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| ATM | To withdraw cash and check bank balance. | PIN entered by the user. | Cash dispensed. |
| Traffic Signal | To control traffic movement. | Timer or vehicle sensor. | Red, yellow or green light. |
| Ticket Machine | To provide tickets for travel. | Destination selected by the user. | Printed ticket. |

### My Understanding

Computer-based systems are used in everyday life to make tasks easier and faster. They receive input, process information and produce output. They are useful in banking, traffic management and ticket booking.
