# The Digital Detective

## About This Project

This repository contains my work for the Diwali Independent Learning Assignment – The Digital Detective.

The purpose of this project is to explore how computers work, understand computer fundamentals, practise Terminal commands, learn Python programming, and understand Git, GitHub and computer networking.
