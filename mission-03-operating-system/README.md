### 2. Commands Used

- `df -h /` – Shows disk storage information.
- `top -l 1` – Displays system activity.
- `ps aux` – Lists running processes.
- `pwd` – Shows the current directory.
- `ls -l` – Displays file details and permissions.

### 3. Operating System Responsibilities

| Responsibility | Description |
|---|---|
| Process Management | Manages running programs. |
| Memory Management | Allocates RAM to programs. |
| Device Management | Controls hardware devices. |
| File Management | Organises files and folders. |
| User Interface | Allows users to interact with the computer. |
| Security | Protects files and controls access. |

### 4. My Understanding

An operating system acts as a bridge between the user and computer hardware. It manages processes, memory, files and devices, and helps programs run efficiently.
